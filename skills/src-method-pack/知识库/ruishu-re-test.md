# 瑞数 JS 挑战（方法论 + 可选项目外置适配器）

本包方法论核心不含瑞数源码、依赖、历史挑战 Cookie、纯算脚本或运行证据。编码绕过 / HPP / 走私仍走 `waf-bypass.md`。本篇只覆盖 **瑞数 412 + `$_ts`**；确需浏览器上下文时，只能使用目标 harness 自己绑定的外置适配器。

## 何时开

首页或接口同时像这些，才按本篇处理：

- HTTP **412** + HTML
- 正文有 `$_ts.nsd`、`$_ts.cd`
- `Set-Cookie` 有以 `S` 结尾的挑战 Cookie
- 另有混淆 mainjs

**不要开：** 普通 403、禁目录、登录表单、没有 `$_ts`。那种按 `dig-scope` 瘦壳 / §4.1.1。

禁止在 412 HTML 上丢 `'` 充四件套。

## 外置适配流程

`{RUISHU_ADAPTER_ROOT}` 必须是目标运行副本自己的私有外置层，且已写入该 harness 的运行时绑定；它不在本包内，也不从本包查找。未绑定时，本包没有过墙能力：记「瑞数墙」，换本种子下一条活 URL，不把 412 当死站。

已绑定时按短生命周期处理：

1. 先确认上面的瑞数特征；只凭 412 不启动。
2. 先执行 `Check`：manifest、wrapper 与本地审计快照齐全且通过后才可用。
3. `Start` 短生命周期桥，只允许本机监听，端口与访问凭据随机；使用一次性隔离浏览器 Profile，不使用个人 Profile。
4. 读取 `{RUISHU_ADAPTER_RUN_DIR}\inject.js`，仅在本次目标页上下文使用，不复制进方法论包。
5. 用 `Status` 确认 `clients` 已含 `ruishu`。
6. 用 `Contract` 生成脱敏验收摘要；挑战材料与现场参数只保留在私有 run 目录或当前任务 dig 目录。
7. `Call get/post` 仅用于 HttpOnly Cookie 或需要浏览器上下文的业务验证。
8. 成功判据是 GET 回 200，或 POST 返回业务响应；随后立刻回 `dig-scope` §4 打业务矩阵。
9. 任务结束必须执行 `Stop`，并确认进程、本机端口与一次性 Profile 均已收掉。

## 止损

- 从识别到放弃总耗时 5～10 分钟。
- 失败记「瑞数墙」，换本种子下一条活 URL。
- 412 不是死站，也不是换资产理由。
- 外置适配器 Check 未通过、未绑定或启动失败时，只报「瑞数适配器暂不可用」，不阻塞 Web SRC。

## 工具边界

- 种子不含瑞数源码、依赖、快照、历史挑战状态、注入脚本或运行证据。
- 默认安装不部署、不复制、不自动运行 Ruishu Adapter。
- 只有目标 harness 已有自己的审计快照、manifest、wrapper，且 `Check` 通过，才允许绑定。
- 绑定路径只写入目标 harness 自己的运行时绑定文件，禁止跨 harness 共享运行状态。
- 禁止自动下载、自动安装依赖或运行未审计纯算脚本；禁止读取或复制顶层采集证据目录。
- 挑战 Cookie、动态后缀、随机访问凭据、注入脚本与验收材料不进对话正文、报告、种子或通用副本。
- `state`、`inject`、`contract` 只保留在 `{RUISHU_ADAPTER_RUN_DIR}` 或当前任务私有 dig 目录。
- 升级采用新目录 + 验证 + 切换绑定 + 保留回滚，禁止原地覆盖正在使用的适配器。

## 不当洞

| 做了啥 | 写不写 |
|--------|--------|
| 过了瑞数、请求变 200 | **不写**。过墙不是权限扩大 |
| 过墙后打穿未授权 / 越权 / 注入 | 按那个洞写，不要写成「瑞数绕过」 |

不进短表（过墙不是高危手法）。本包短表只读。
