# 安装

Person-Pentest 的默认安装方式是**安装模式（运行副本模式）**：目标 harness 复制方法论核心到自身可写域，生成自己的 `适配.md`，并注册持久入口。**装载模式是显式兼容模式**，只服务当前会话，不作为默认，也不作为安装失败后的自动降级。

不要把“当前会话已经读过包”误判成“已安装后可脱离包”。

## 0. 执行主体与边界

- 安装在**目标 harness** 会话内执行：用户向目标 harness 给定种子目录或解压后的包根绝对路径，并由该 harness 复制方法论核心到自身可写域，注册自己的持久入口。
- 用户向目标 harness 给出包根并要求安装，或使用 `给通用harness的提示词.txt` 的默认安装块，即视为安装指令；路径有效且自身可写域明确后直接执行，不再重复询问“要不要安装”。
- 种子只作为输入源，不作为控制端。
- 禁止在 A harness 中修改 B harness 的配置、skill、项目提示词或运行副本。
- 安装验收也在目标 harness 新会话中完成；其它 harness 不代装、不代验。
- 目标 harness 无法创建运行副本或无法注册持久入口时，报告缺项并停止；不要静默降级为装载模式。

## 1. 默认模式与兼容模式

### 1.1 安装模式（运行副本模式，默认）

- 做法：按 `安装-运行副本模式.md` 复制方法论核心到 harness 或项目的运行副本目录，生成运行副本自己的 `适配.md`，并注册持久入口。
- 触发：用户把包根给目标 harness 并要求安装、要求建立运行副本，或粘贴 `给通用harness的提示词.txt` 的默认安装块。
- 已有完整运行副本：只校验和补齐持久入口，不覆盖方法论正文。
- 已有残缺运行副本：保留其 `适配.md`、持久入口和专属文件，只修复缺失核心；不隐式升级。
- 显式升级 / 重装：必须由用户点名；否则重复安装请求按已安装校验处理。
- 效果：新会话通过项目提示词、skill 注册或等效启动入口直接找到运行副本；方法论正文不再依赖桌面种子。
- 依赖：运行副本与持久入口。FOFA 是独立可选部署：未部署时报测绘暂不可用，不阻塞 Web SRC。桌面种子可移动或删除；可选工具是否可用见下文边界。
- 完成标志：新会话触发 `PP` / `Person-Pentest` / `src-method-pack` 时读取运行副本，且不再回桌面种子定位。

### 1.2 装载模式（显式兼容，非默认）

- 触发：用户明确说“临时装载”“不安装运行副本”“只给当前会话装载”，或直接提供装载语义提示词。
- 做法：让当前会话读取种子包根，按 `短系统提示.md`、`SKILL.md` 指定节和 `适配.md` 完成本次装载。
- 效果：只对当前会话生效。新会话、重启后，包不会自动进入上下文，需要重新装载。
- 依赖：种子文件夹仍然是方法论来源；移动或删除后，后续会话需重新提供新路径。
- 定位：这不是安装器，也不是持久安装完成状态。
- 边界：安装失败、无法写盘或无法注册持久入口时，不得自动改用装载模式；只有用户显式选择才进入本模式。

## 2. 使用前检查（人做，不进挖洞任务）

任务开头既没读到红线、也没先判锁面/自由跳，按环境未挂好处理，停在使用前流程。

1. 系统提示或等效最高优先级入口贴上 `/home/lotso/artex-ymh/skills/src-method-pack/短系统提示.md` 全文。安装模式下，`/home/lotso/artex-ymh/skills/src-method-pack` 指运行副本绝对路径；装载模式下，`/home/lotso/artex-ymh/skills/src-method-pack` 指种子包根绝对路径。
2. 技能挂 `/home/lotso/artex-ymh/skills/src-method-pack/SKILL.md`，`name` 必须是 `src-method-pack`。
3. 适配：落盘父目录必填；任务根在执行测试任务时自动在其下按 `{任务}_SRC挖洞` 派生，平时留空。
4. 安装模式另需确认持久入口已注册，新会话能自动找到运行副本。

自检：短提示已进入系统提示或等效入口；技能名是 `src-method-pack`；落盘父目录有绝对路径；任务根留空待派生；安装模式不回桌面种子定位；装载模式仍依赖种子包根。

## 3. 方法论核心与工具边界

安装模式复制的方法论核心为：`SKILL.md`、`短系统提示.md`、`rules/`、`知识库/`、`human-writing/`，并生成运行副本自己的 `适配.md`。说明文档可另复制。不复制 `mcp/`、`tools/`、`.env`、`node_modules`、`.venv/`、`__pycache__/` 或凭据。

可选工具不随默认安装自动部署。已有则绑定校验；没有则报告暂不可用，不阻塞 Web SRC；用户点名时再单独安装。

### 3.1 测绘（FOFA MCP，独立部署）

- 默认安装不自动部署 FOFA MCP。目标 harness 已有独立部署副本时直接绑定；没有则报告测绘暂不可用。
- 需要部署时，种子源码位于 `{种子包根}/mcp/fofa/`，复制到目标 harness 自己的域（Codex 示例：`C:\Users\<user>\.codex\mcp\fofa\`），MCP 注册指向部署副本。
- 部署命令：`uv run --directory <部署目录> fofa.py`（stdio），服务名建议 `fofa`（源码服务名是 `fofasearch`）。
- 工具本名 `get_alerts`；别名 `fofa`。认任一名字。
- Key：只存部署副本的 `.env`。不要把 key 写进 SKILL、包内 `.env`、项目提示词或对话。
- 独立部署完成后，移动或删除桌面包不影响该 MCP；包更新 `mcp/fofa` 后重新部署一次即可。
- 调用：自由跳优先 `query`（原始 FOFA 语法）+ `page`/`size`。`status_code` 默认不传。401/403/登录墙算存活。
- 限流：部署副本 `.env` 可填备用号变量，按主号 → backup → backup2。

### 3.2 浏览器（Playwright MCP）

- 安装 `@playwright/mcp` 或等价 Playwright MCP；不随方法论默认安装自动处理。
- 服务名建议 `playwright`。
- 本名 `browser_navigate` / `browser_snapshot` / `browser_click` 等；前缀名 `playwright__` + 本名。
- 有前缀用前缀，没有用本名；确需页面且两套都没有，停在使用前流程。
- HTTP/API、curl、raw replay 已能验证时，不启动浏览器。

### 3.3 小程序 WMP（可选外部工具）

- 目标状态：安装到与桌面种子无关的外部路径，默认 `C:\tools\<工具发布名>\`；Codex 当前示例为 `C:\tools\WMP-pentest-automation-v1.1.0\`。
- 目标 harness 先检查外部路径：已存在则直接绑定；不存在且用户点名需要 WMP 时，才把种子 `tools/wmp/` 当作安装载荷，安装或复制到外部工具目录并完成依赖检查。
- 安装后由目标 harness 把 WMP 绝对路径写入自己的运行时绑定文件；新会话只按该绑定调用，禁止回桌面种子 `tools/wmp/` 找运行入口。
- 多 harness 可共享同一份只读工具代码；offset、配置、token、日志、会话等运行状态必须按 harness 隔离。若 WMP 无法把运行状态从工具代码中分离，则该 harness 使用独立工具副本。
- 升级时安装到新版本目录，验证可用后只切换绑定路径，旧版本保留用于回滚；禁止原地覆盖正在使用的工具目录。
- 没点名小程序不在任务里催装。WMP 缺失只报小程序链路暂不可用，不阻塞 Web SRC。收集方法见 `知识库/miniprogram-test.md`。`tools/wmp/` 里若还有其它 `SKILL.md`，不作为 SRC 主技能。

### 3.4 sqlmap FluX（可选外部工具）

- 目标状态：安装到与桌面种子无关的外部路径，默认 `C:\tools\Sqlmap-FluX-<版本或发布名>\`；Codex 当前示例为 `C:\tools\Sqlmap-FluX-main\sqlmap.py`。
- 目标 harness 先检查外部入口：已存在则直接绑定；不存在且用户点名需要 sqlmap 时，才从种子 `tools/sqlmap-flux/` 安装或复制到外部工具目录。
- 安装后由目标 harness 把 sqlmap 入口绝对路径写入自己的运行时绑定文件；新会话只按该绑定调用，禁止回桌面种子 `tools/sqlmap-flux/` 找运行入口。
- 升级时安装到新版本目录，验证可用后只切换绑定路径，旧版本保留用于回滚。
- 仅手工确认 SQL 注入后使用。与目标连接中断时，可能需要 `--proxy=`（地址自行填写）。

### 3.5 Ruishu Adapter（可选项目外置层）

- 目标状态：安装在当前项目私有 tools 域；该层不进入可分发种子。
- 启用前先检查绑定与本地快照，并执行 `Check`；Check 通过才允许 `Start`。
- 生命周期只按 `Check / Start / Status / Contract / Call get/post / Stop` 调度；服务仅绑定本机，端口与访问凭据随机。
- 使用一次性隔离浏览器 Profile；不自动下载、不自动安装依赖，不运行未审计脚本。run 目录、state、inject、contract 按当前 harness 隔离。
- 任务结束执行 `Stop`，确认无残留进程、本机端口和一次性 Profile。
- 未绑定或 Check 失败时报「瑞数适配器暂不可用」，按瑞数墙止损，不阻塞 Web SRC。

### 3.6 Android（本机环境）

`知识库/android-app-test.md` 中的 ADB / PKR110 / Frida 表只适用于本机对应设备。对不上时不盲连无线 IP。没点名 App 不打开本篇。

### 3.7 WMP / sqlmap / Ruishu Adapter 外部工具验收（可选）

只在用户点名需要 WMP、sqlmap 或 Ruishu Adapter 时执行，不作为方法论安装的硬性验收：

1. 绑定路径是外部绝对路径，且入口存在。
2. WMP 入口 / doctor / 等价自检可运行；sqlmap 入口 / 版本或帮助信息可运行；Ruishu Adapter 已绑定时先执行 Check，Check 通过才算可启用。
3. 目标 harness 的绑定文件指向外部工具路径，未指向桌面种子 `tools/`。
4. 新会话读取绑定后仍能定位工具。
5. 需要证明脱离种子时，可临时移走或屏蔽桌面种子再复测；测试后恢复种子。该隔离验证是工具验收项，不是 Web SRC 方法论安装阻塞项。
6. Ruishu Adapter 未绑定时只报「瑞数适配器暂不可用」，不阻塞 Web SRC；已绑定时 Check 通过才可启用，Stop 后复验无残留进程、本机端口和一次性 Profile。

## 4. 写盘

能在 `{任务根}` 创建 `资产/`、`js/`、`报告/`、`{名}_dig/`。任务根按执行任务时的目标名自动派生，禁止按字面创建名为 `{任务根}` 的目录。
