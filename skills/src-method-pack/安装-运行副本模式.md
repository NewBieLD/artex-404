# 安装（运行副本模式，默认）

本文件是 Person-Pentest 的默认安装流程。目标是让目标 harness 建立自持运行副本：安装完成后，新会话不回桌面种子定位，方法论正文可脱离安装文件夹。

装载模式只是显式兼容模式，不是默认路径，也不是安装失败后的自动降级。

## 0. 执行主体与边界

- 本流程由**目标 harness** 自己执行。正常输入是用户在该 harness 会话中给定的种子目录或解压后的包根绝对路径。
- 用户把包根给目标 harness 并要求安装，或粘贴 `给通用harness的提示词.txt` 的默认安装块，即视为安装指令；路径有效且自身可写域明确后直接执行。
- 目标 harness 只写自己的 harness 域或项目域，生成自己的运行副本、`适配.md` 和持久入口。
- 用户负责选择目标 harness、提供种子包根路径；无需再重复确认“要不要安装”，除非目标 harness 自身存在必须由用户裁决的写入位置冲突。
- 禁止从 A harness 远程修改 B harness 的配置、skill、项目提示词或运行副本。
- 安装完成后，在目标 harness 新会话中触发 `PP` / `src-method-pack` 验证；其它 harness 不代验。
- 无法创建运行副本、无法生成 `适配.md` 或无法注册持久入口时，停止安装并报告缺项；不得静默降级为装载模式。

## 1. 安装前检查与已有副本分支

源包同一层必须存在：

- `SKILL.md`
- `短系统提示.md`
- `rules/`
- `知识库/打穿短表.md`
- `适配.md`

缺项则停止安装并只报告缺项。`mcp/`、`tools/` 缺失不阻塞方法论安装，只在自检中记录测绘或可选工具暂不可用。

已有运行副本时按以下分支处理：

| 状态 | 默认动作 |
|---|---|
| 不存在 | 新建运行副本，复制方法论核心，生成自己的 `适配.md`，注册持久入口 |
| 完整 | 校验必需文件、适配锚点、持久入口和外部工具绑定；不覆盖正文，不重复注册冲突入口 |
| 残缺 | 保留运行副本自己的 `适配.md`、持久入口和专属文件；只补齐缺失的方法论核心文件 |
| 需要换版本 | 必须由用户显式说“升级”“重装”或“用新种子更新”；否则不得覆盖 |

重复粘贴安装提示词不是升级指令。

## 2. 选择运行副本目录

目录应放在 harness 或项目自持域，不放在桌面种子内。

示例：

- Codex 项目运行副本：`<项目根>\.codex\person-pentest\`
- 其它 harness：选择其项目配置域、skill 域或等效持久目录。

禁止：

- 放入桌面种子内部。
- 放入临时目录、下载目录或随任务删除的目录。
- 直接堆到用户主目录的隐藏产品配置夹。
- 按字面创建 `/home/lotso/artex-ymh/skills/src-method-pack`、`{任务根}` 这类占位符目录。

## 3. 复制方法论核心

新装时复制：

- `SKILL.md`
- `短系统提示.md`
- `rules/`
- `知识库/`
- `human-writing/`
- 可选说明文档：`安装.md`、`给通用harness的提示词.txt`、`安装-运行副本模式.md`、`来源.md`

禁止复制：

- `mcp/`
- `tools/`
- `.env`
- `node_modules`
- `.venv`
- `__pycache__`
- 任何凭据、Key、cookie、token、会话材料

FOFA MCP 不随方法论核心复制。需要测绘时，按 `安装.md` 独立部署到 harness 域；未部署只报测绘暂不可用。

## 4. 可选外部工具安装态（WMP / sqlmap FluX / Ruishu Adapter）

原则：

- WMP、sqlmap FluX 与 Ruishu Adapter 是可选外部工具，不是方法论核心；均不随默认安装自动部署。
- 缺失只报对应工具暂不可用，不阻塞 Web SRC。
- 目标 harness 在自身会话内安装和绑定；禁止 A harness 替 B harness 安装、修改配置或验收。
- 默认安装到 `C:\tools\<工具发布名或版本>\`，形成与桌面种子无关的外部工具层。
- 先检查外部路径：已存在则只绑定；不存在且用户点名需要该工具时，才把种子 `tools/` 当作安装载荷，安装或复制到外部工具目录。
- 方法论运行副本不复制 `tools/`、`node_modules/`、`.venv/`、`__pycache__/` 或凭据。
- 目标 harness 把工具绝对路径写入自己的运行时绑定文件；新会话禁止回桌面种子 `tools/` 定位运行入口。
- WMP 多 harness 可共享只读工具代码；offset、配置、token、日志、会话等运行状态必须按 harness 隔离。无法隔离时使用独立工具副本。
- 升级采用新版本目录 + 切换绑定 + 旧版本回滚，禁止原地覆盖正在使用的工具目录。
- Ruishu Adapter 是可选项目私有外置层，不随桌面种子分发；种子里没有安装载荷，安装流程禁止从种子查找或复制。
- 只有目标 harness 已有自己的审计快照、manifest、wrapper 且 Check 通过，才把 `{RUISHU_ADAPTER_ROOT}` 写入自己的运行时绑定文件；绑定后按 `知识库/ruishu-re-test.md` 短生命周期使用。
- `{RUISHU_ADAPTER_RUN_DIR}` 中的状态、注入脚本和验收摘要按 harness 隔离；任务结束 Stop，并确认无残留进程、端口或一次性 Profile。

## 5. 生成运行副本适配

在运行副本中新建或更新自己的 `适配.md`：

| 栏 | 填法 |
|---|---|
| 包根 | 运行副本绝对路径 |
| 落盘父目录 | 该 harness 对应的任务父目录绝对路径 |
| 任务根 | 平时留空；执行测试任务时自动派生 `{任务名}_SRC挖洞` |

规则：

- 不复制、不覆盖桌面种子的 `适配.md`。
- 安装后新会话以运行副本 `适配.md` 为锚点。
- `落盘父目录` 优先使用目标 harness 已配置的稳定任务父目录；没有既有约定时，可派生到目标项目内的 pentest 区域，例如 `<项目根>\pentest\<harness标识>-pentest`。
- `落盘父目录` 必须是有效绝对路径；无法安全确定时不猜系统目录，停止安装并报告。
- 任务根不是父目录，也不是字面 `{任务根}`。
- 派生任务根后按 `rules/desktop-task-folder.md` 建齐 `资产/`、`js/`、`报告/`、`{名}_dig/`。

## 6. 注册持久入口

注册动作同样由目标 harness 在自身配置域内完成。任选 harness 支持的等效方式，但必须让**新会话**自动找到运行副本：

- 项目提示词 / 项目 AGENTS loader
- skill 注册，`name=src-method-pack`
- harness 启动时注入的系统提示
- 其它等效持久配置

入口内容至少写清：

1. 运行副本绝对路径。
2. 触发词：`PP`、`Person-Pentest`、`src-method-pack`、`SRC 挖洞`、渗透测试、漏洞挖掘、白盒审计等。
3. 加载顺序：先读运行副本 `短系统提示.md`；再读 `SKILL.md` 的「安全红线 1～11」「自由跳节奏红线」「对得上再开」；再读运行副本 `适配.md`；随后按短提示读指定资料。
4. 禁止回桌面种子或全局 skills 查找入口。
5. FOFA Key 只读独立部署副本 `.env`。
6. 任务根由落盘父目录自动派生，禁止按字面创建 `{任务根}`。

仅当前会话读过运行副本不算安装完成；新会话验证通过才算完成。

## 7. 安装后验证

以下检查在目标 harness 内执行；用户在目标 harness 新会话中触发验收。

1. 必需方法论文件存在。
2. 运行副本 `适配.md` 的包根等于运行副本绝对路径，落盘父目录必须是有效绝对路径；空值不算验收通过。
3. 运行副本无 `.env`、无 `mcp/`、无 `tools/`、无 `node_modules`。
4. 新开会话触发 `PP` / `src-method-pack`，读取的是运行副本，不访问桌面种子。
5. FOFA 由独立部署副本提供；未部署时报告测绘暂不可用，不阻塞 Web SRC。
6. WMP / sqlmap / Android 表 / Ruishu Adapter 按可选外部工具处理：已安装或已绑定则确认路径与自检有效；未安装或未绑定则报对应工具暂不可用，不阻塞 Web SRC。
7. 点名使用 WMP / sqlmap 时，新会话确认绑定不回桌面种子 `tools/`；需要证明脱离种子时，可临时移走或屏蔽桌面种子复测，测试后恢复。
8. Ruishu Adapter 按「已绑定 / 未绑定」验收：已绑定则 Check 通过、run 状态按 harness 隔离、Stop 后无残留；未绑定只报「瑞数适配器暂不可用」，不阻塞 Web SRC。

## 8. 升级与回滚

升级必须由用户显式点名“升级”“重装”或“用新种子更新”：

1. 备份当前运行副本中会被覆盖的说明文档和方法论核心。
2. 保留运行副本自己的 `适配.md`、持久入口、工具绑定和项目专属文件。
3. 从新种子复制方法论核心与说明文档。
4. 不覆盖持久入口配置，除非入口格式需要变更。
5. 重新执行第 7 节验证。

回滚：

1. 移除持久入口中对运行副本的指向。
2. 按需归档运行副本目录。
3. 需要继续使用临时装载模式时，由用户显式选择并重新提供桌面种子路径。

## 9. 桌面种子删除边界

安装并验证完成后，删除桌面种子：

- 不影响运行副本中的 Web SRC 方法论。
- 不影响独立部署的 FOFA MCP。
- 不影响已安装并绑定到外部路径的 WMP、sqlmap FluX、Playwright MCP 或 Android 工具链。
- 若某 harness 未执行外部工具安装，仍只依赖种子 `tools/`，删除桌面种子后该工具报暂不可用；这属于可选工具未安装，不是方法论安装失败。

## 10. 临时装载兼容模式

临时装载只在本节显式启用：

- 用户必须明确说“临时装载”“不安装运行副本”或同等语义。
- 目标 harness 以种子包根为本次会话方法论来源。
- 效果仅限当前会话，新会话需重新装载。
- 不生成运行副本，不注册持久入口，也不代表安装完成。
- 安装失败不得自动进入本模式。
