## 路径口径（Artex 运行时）

Artex 平台已为每个任务分配独立工作目录，agent 的 Bash/Read/Write 默认 cwd 即该目录：

```
{任务根} = /home/lotso/artex-ymh/data/tasks/<taskID>            （planner / mainagent 运行目录）
         = /home/lotso/artex-ymh/data/tasks/<taskID>/i<intentID> （worker 单次执行目录）
```

规则：

- 四类分夹 `资产/` `js/` `报告/` `{名}_dig/` 与 `README.md` **直接建在当前工作目录下**，不要再嵌套一层 `{任务名}_SRC挖洞`（任务工作目录本身已按任务隔离，等同于任务根语义）。
- 文档中出现的 `{任务根}` 一律按上表映射到当前 agent 的工作目录；禁止按字面创建名为 `{任务根}` 的目录。
- 跨 intent 续跑仍进同一任务工作目录（`data/tasks/<taskID>`），不要另开散目录。

## 与平台约束的关系

Artex 的拦截规则（`intercept_rules`）在工具调用层生效，优先级高于本技能红线；本技能的红线（1～11 条）是方法论口径，两者同时生效、取交集更严的一侧。平台侧「登出用户会话禁止」「破坏性命令拦截」等底线与技能红线 2/6/7 口径一致。
